# 4. Prime factorization (разложение на простые множители)

## Идея

Простое число имеет ровно два положительных делителя: 1 и само себя. Разложение числа `n` на простые множители — запись

`n = p₁^a₁ · p₂^a₂ · ...`,

где все `pᵢ` простые. Например, `84 = 2² · 3 · 7`.

Ниже предполагается `n >= 1`: у `1` нет простых множителей, поэтому функция вернёт пустой список.

## Алгоритм делением

Пробуем делители `p` от 2 до `sqrt(n)`. Пока `p` делит число, добавляем `p` в ответ и делим `n`. Если после цикла осталось `n > 1`, это последний простой множитель.

```cpp
#include <iostream>
#include <vector>

std::vector<long long> factorize(long long n) {
    std::vector<long long> factors;
    for (long long p = 2; p <= n / p; ++p) {
        while (n % p == 0) {
            factors.push_back(p);
            n /= p;
        }
    }
    if (n > 1) factors.push_back(n);
    return factors;
}

int main() {
    for (long long p : factorize(84)) std::cout << p << ' '; // 2 2 3 7
}
```

Условие `p <= n / p` безопаснее, чем `p * p <= n`: оно не допускает переполнения. В худшем случае (например, простое `n`) алгоритм делает `O(sqrt(n))` проверок и использует `O(k)` памяти для `k` найденных множителей; если считать только счётчики, дополнительная память `O(1)`.

## Почему достаточно идти до корня

Если составное число `n` имеет делитель больше `sqrt(n)`, парный делитель обязательно меньше `sqrt(n)`. Значит, до корня мы найдём хотя бы один множитель. После делений оставшееся `n` уже простое.

## Частые ошибки

- забыть обработать остаток `n > 1`;
- увеличить `p` только один раз и пропустить степень (`12` должно дать `2, 2, 3`);
- использовать `int` для больших произведений и получить переполнение;
- считать `1` простым (это не так).
