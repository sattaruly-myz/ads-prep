# 3. Deque (двусторонняя очередь)

## Идея

`deque` (*double-ended queue*) позволяет быстро добавлять и удалять элементы **с обоих концов**. В отличие от стека и очереди, доступны начало и конец.

Операции `std::deque`:

- `push_front`, `pop_front`, `front`;
- `push_back`, `pop_back`, `back`;
- индекс `d[i]`, `size`, `empty`.

```cpp
#include <deque>
#include <iostream>

int main() {
    std::deque<int> d = {2, 3};
    d.push_front(1); // 1 2 3
    d.push_back(4);  // 1 2 3 4
    d.pop_front();   // 2 3 4
    d.pop_back();    // 2 3
    std::cout << d.front() << ' ' << d.back() << '\n';
}
```

Операции на концах — `O(1)`, доступ по индексу — `O(1)`, но элементы не обязаны лежать одним непрерывным блоком, поэтому `deque` не равен `vector`. Память — `O(n)`.

## Типичные применения

- скользящее окно (удаляем устаревшие элементы слева, добавляем новые справа);
- 0–1 BFS (вес ребра 0 добавляется в начало, вес 1 — в конец);
- палиндромы (сравниваем элементы с двух концов);
- монотонная очередь для максимума/минимума на отрезке.

Проверка палиндрома:

```cpp
#include <deque>
#include <string>

bool isPalindrome(const std::string& s) {
    std::deque<char> d(s.begin(), s.end());
    while (d.size() > 1) {
        if (d.front() != d.back()) return false;
        d.pop_front();
        d.pop_back();
    }
    return true;
}
```

## Выбор контейнера

Нужна только верхушка — `stack`. Нужны строго FIFO-операции — `queue`. Нужны оба конца или индексный доступ — `deque`. Нужны непрерывные данные и быстрый `data()` — `vector`.
