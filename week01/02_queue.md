# 2. Queue (очередь)

## Идея

Очередь работает по правилу **FIFO** (*First In, First Out*): кто пришёл первым, тот обслуживается первым. Это очередь людей в магазине.

Операции `std::queue`:

- `push(x)` — добавить в конец;
- `pop()` — удалить элемент из начала;
- `front()` — посмотреть первый;
- `back()` — посмотреть последний;
- `empty()`, `size()`.

```cpp
#include <iostream>
#include <queue>

int main() {
    std::queue<std::string> q;
    q.push("Alice");
    q.push("Bob");
    q.push("Cara");

    std::cout << q.front() << '\n'; // Alice
    q.pop();
    std::cout << q.front() << '\n'; // Bob
}
```

Все основные операции очереди — `O(1)`, а память — `O(n)`. Как и у стека, нельзя обращаться к `front`, `back` или `pop` у пустой очереди.

## Почему нельзя удалять из начала `vector`

`vector.erase(begin())` сдвигает все оставшиеся элементы и занимает `O(n)`. Для обычной очереди это плохая реализация. Используй `std::queue` (по умолчанию на `deque`) или храни индекс начала в массиве.

Простая идея массива с индексом:

```cpp
#include <vector>

class SimpleQueue {
    std::vector<int> data;
    std::size_t head = 0;
public:
    void push(int x) { data.push_back(x); }
    int front() const { return data.at(head); }
    void pop() { ++head; }
    bool empty() const { return head == data.size(); }
};
```

В настоящей реализации нужно также периодически освобождать уже использованное начало, иначе память будет расти.

## Где применяется

Очередь моделирует задания принтера, запросы сервера и обход графа в ширину (BFS). В BFS вершину добавляют в очередь, а затем обрабатывают по слоям: сначала расстояние 0, потом 1, 2 и так далее.

## Запомни

У очереди две роли: добавляем сзади (`back`), забираем спереди (`front`).
